# BedWars

## Requisitos

- Java 21+ (ou a versão do projeto)
- Maven 3.9+

## Comandos

### Compilar
```bash
mvn clean compile
```

### Executar testes
```bash
mvn test
```

### Gerar JAR
```bash
mvn clean package
```

### Instalar no repositório local
```bash
mvn clean install
```

### Executar a aplicação (Spring Boot)
```bash
mvn spring-boot:run
```

### Limpar arquivos gerados
```bash
mvn clean
```

### Atualizar dependências
```bash
mvn dependency:resolve
```

### Ver árvore de dependências
```bash
mvn dependency:tree
```
